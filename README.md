# Res Publica — 布匿战争时代（罗马全战开源简化版）

回合制大战略 + 行省模拟经营。战役窗口：**布匿战争 → 马略改革前（公元前 264–107 年）**，波利比乌斯军制时代。首发剧本：公元前 218 年第二次布匿战争。

**双击 index.html 即可运行**（纯静态 HTML/JS，无依赖、无构建、可离线）。

## v3：税赋转运 + 中央军/边军 + 招募费用矩阵

- **税赋季度转运（拒绝即时转账）**：行省每季税收 60% 装车运往国库——路径每格损耗 4%（越远越损耗）、陆路距离 >4 步或忠诚 <40 的边远行省干脆不上缴（天高皇帝远）；在途税款下一季才到账。顶栏显示国库与中央粮储。
- **中央军 / 边军（由组建地点锁定身份）**：首都组建 = 中央军，外地组建 = 边军。中央军远离首都作战时占用驻省金库粮库（就地征发）；边军完全就地取饷。**禁卫军团/执政官卫队只能在首都招募**，损耗后只能回京补充——迫使玩家保持员额。
- **招募费用矩阵**（同一兵种，身份决定价格）：

| | 本国公民兵 | 当地雇佣军 |
|---|---|---|
| **中央军** | ×1.0（低成本动员公民） | ×1.5（中央不熟佣兵行情） |
| **边军** | ×1.8（公民兵拉到边疆极贵） | ×0.8（就地雇人便宜） |

  非核心文化区招募一律视为辅兵（士气 -20%，走佣兵费率）。佣兵需市场建筑 + 对应特产兵源 ≥2。
- **敌境以战养战**：军团在敌境驻扎时按 `fieldSupply` 掠夺当地，不再依赖国内输血。

## v2：军团制 + 六边形战术层 + 分省后勤

- **军团制**：全军以军团为单位（上限 20 队，可自定义编号），招募自动编入驻省军团；将领特质随军团生效。
- **六边形战术层**（独立于战略视图）：接敌后进入 15×11 六边形战场——布阵（可手动调整己方 3 行部署）→ 选战术（自动接近 / 就地防御）→ 逐轮自动推演。远程射程 2 格；**火力遮蔽**：越过己方近战开火有 40% 概率误伤友军；骑兵/战象移动后接敌触发冲击加成；森林/丘陵提供防御加成。也可一键「自动结算」走战略快算。
- **后勤改革（拒绝全局共享）**：钱粮分省储存——每省自己的金库/粮库，建设与招募花本省金库；军团随军粮草有限，敌境行军只吃自带的，断粮即减员；攻占敌城可掳获一半钱粮（另一半在混乱中散失）；在非核心文化区可征募当地辅兵（士气 -20%，花费 +20%）。军饷按历史 tributum 制由全国省库摊派。
- **复用开源库**：六边形网格数学全部复用 [honeycomb-grid v4](https://github.com/flauwekeul/honeycomb-grid)（MIT，UMD 构建本地化于 `js/lib/`）——距离/邻接/寻路/像素换算不重复造轮子；游戏规则（克制矩阵/误伤/补给）为自研。

## 设计支柱：对《全面战争·罗马》三大诟病的机制回答

| 诟病 | 机制对策 |
|---|---|
| 外交关系僵化，势力反转太慢 | 关系值每回合向「实力均衡点」快速回归；任何势力膨胀过快（实力比 >1.5）自动招致全邻国敌意（反霸权修正）；仅「血仇」标记（罗马-迦太基）持久 |
| 贸易不反映特产价值 → 无脑种田 | 特产按稀缺度定价：谷物 1.0 / 橄榄·酒 1.5 / 银矿 3.0 / 努米底亚马 2.0 / **昔兰尼加 silphium 4.0（全图独一份）**；纯粮行省税基远低于贸易行省 |
| 无脑堆最便宜征召枪兵 | ①战线宽度上限 24 战位，超出宽度的部队纯吃伤亡不上战力 ②远程对低甲杀伤加成 ③征召兵士气池 ×0.6 易崩 ④近战克制矩阵（征召 vs 重步 = 0.5）⑤战象无远程掩护会恐慌反踩己方（扎马） |

## 兵种七类（写入军团代码）

- **LR 轻装远程**：巴利阿里/罗得岛投石手、克里特弓箭手、罗马青年兵（velites）
- **LI 轻装近战**：色雷斯人、培尔塔斯特、加拉太战士、伊比利亚轻步兵
- **HI 重装步兵**：罗马军团（波利比乌斯三线轮换）、希腊重装、马其顿方阵（正面+35%/被包抄-40%）、利比亚长枪、圣团
- **LC 轻骑兵**：努米底亚轻骑（无鞍骑手）、塔兰托轻骑
- **HC 重骑兵**：伙友骑兵、罗马骑士、坎帕尼亚重骑、高卢贵族骑
- **EL 战象**：印度象（塞琉古塔楼象）> 北非象 > 非洲森林象
- **LV 征召**：征召枪兵（便宜、易崩、被远程收割）

将领特质直接作用于兵种类别：大西庇阿（轻装远程/轻近战 +25%）、汉尼拔（轻骑+20%/伏击/夜战）、费边（守势+25%）、腓力五世（重步+15%）、安条克三世（重骑+20%/象+15%）。

## 行省经济（30 行省，历史特产修正）

埃及谷物（罗马 1/3 供粮地）、外西班牙/近西班牙银矿、达契亚式金矿逻辑的西班牙矿产、西西里粮仓、克里特佣兵弓手、努米底亚骑兵兵源、昔兰尼加 silphium。城市可建设：谷仓/兵营/市场/手工作坊/港口/城墙/马厩/象栏。忠诚度 = 文化 + 驻军 + 新征服惩罚；低于 20 爆发起义。
